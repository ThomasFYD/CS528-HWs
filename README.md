# CS528 Homework Repository

Homework projects for CS528 Cloud Computing at Boston University.

Author: Yide Fang

## Homework

- [Homework 1: Google Cloud Resource Management](CS528-HW1/README.md) — Document Cloud Console operations for storage, virtual machines, and service accounts. [Report](CS528-HW1/report/CS528_HW1_Report.pdf).
- [Homework 2: Web Graph Analysis](CS528-HW2/README.md) — Build a graph from 12,000 HTML files in Cloud Storage and compute degree statistics, PageRank, and closeness centrality.
- [Homework 3: HTTP Services and Pub/Sub](CS528-HW3/README.md) — Serve HW2 files through a Python cloud function, filter requests by country, and use a local Pub/Sub subscriber to persist denied-request logs.
- [Homework 4: Compute Engine Services and Performance](CS528-HW4/README.md) — Automatically provision Python web and Pub/Sub reporter VMs, verify HTTP behavior, measure performance with one to four instructor clients, and delete the dedicated resources. [Report and figures](CS528-HW4/report/CS528_HW4_Report.pdf).

- [Homework 5: Cloud SQL Request Logging and Operation Timing](CS528-HW5/README.md) — Persist request metadata and failures in MySQL, measure four server operations, and analyze a verified 100,000-request experiment. [Report](CS528-HW5/report/CS528_HW5_Report.pdf).

HW1 contains a screenshot-based Cloud Console report. The HW2-HW5 READMEs describe implementation, dependencies, configuration, and tests. The HW3 PDF report is submitted separately through Gradescope. The HW4 and HW5 folders include their PDF reports and reviewed experiment evidence.
